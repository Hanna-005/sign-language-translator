# Sign Language Translator

A real-time sign language translator built with Python and Flask. It uses a webcam to capture hand signs, and a machine learning model recognizes each sign and converts it into the matching alphabet letter, displayed as text on screen to help bridge communication.

## Features
- Real-time hand sign detection using a webcam
- Converts signs into alphabet letters
- Displays the predicted letter as text on screen

## Tech Used
Python, Flask, HTML, CSS, JavaScript, Machine Learning

## How to Run
1. Clone this repo
2. Go to the project folder: `cd SignToText`
3. Install libraries: `pip install -r ../requirements.txt`
4. Run: `python app.py`
5. Open the local link shown in the terminal
